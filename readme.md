# About
([pt-br](readmePT.md)) Final project in Computer Programming II for the Electronic Engineering course - IFSC.  

# Objectives
Create a vending machine that contains: 
- At least one data structure (List, Stack, Queue)
- A finite state machine
- File manipulation
- Display advertisements
Linux and Windows compatibility. 
  
# Project structure
- rel (Build folder)  
- src  
    - data (Data structure implementation)  
    - modules (Vending machine modules)

- Use provided vscode task.
