# Sobre
([en](readme.md)) Projeto final disciplina Programação de computadores II para o curso de Engenharia Eletrônica - IFSC.  

# Objetivo
Criar uma máquina de venda de refrigerantes que contenha: 
- Pelo menos uma estrutura de dados (Lista, Stack, Fila)
- Uma máquina de estados
- Manipulação de arquivos
- Exiba propagandas
Compatibilidade Linux e Windows. 
  
# Organização de arquivos
- rel (Saída de compilação)  
- src  
    - data (Implementação estrutura de dados)  
    - modules (Modulos da máquina de venda)
